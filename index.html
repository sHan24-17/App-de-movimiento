Guía de Conexión a Firebase

ℹ️ ¿Cómo conectar tu proyecto de Firebase?

  1. Entra a la consola: console.firebase.google.com.
  2. Crea un proyecto (o abre uno existente).
  3. En el menú izquierdo ve a Compilación > Firestore Database y crea tu base de datos en Modo Prueba.
  4. En la configuración del proyecto (icono de engranaje ⚙️) agrega una App Web (</>).
  5. Copia el bloque const firebaseConfig = { ... } y pégalo abajo, o rellena los campos.
